Linear Map Lemma 

v(1) ... v(n) : basis of V
w(1) ... w(n) : in W

then 
exists unique linear map T: V->W

      T
v(k) ---> w(k)

===================================================

Proof of Linear Map Lemma : Uniqueness

suppose linear map T : V -> W 

                 T 
            v_k --->             w_k  
       (c_k)v_k --->        (c_k)w_k : by Homogeneity
sum of (c_k)v_k ---> sum of (c_k)w_k : by Additivity

===================================================

Proof of Linear Map Lemma : Exstence

                 T
sum of (c_k)v_k ---> sum of (c_k)w_k

(1) well-defined : v(k) has unique w(k)

(2) Tv(k) = w(k) : c(k) = 1 and other c's = 0

(3) Additivity

                             T 
  u =    sum of [ a_k ] v_k --->   sum of [ a_k ] w_k  =   Tu 
+ v    + sum of [ c_k ] v_k      + sum of [ c_k ] w_k    + Tv 

(4) Homogeneity

                          T 
    sum of (a * c_k) v_k --->     sum of (a * c_k) w_k 
= a sum of (c_k) v_k          = a sum of     (c_k) w_k
= a v                         = a T(v)  

===================================================

3B. Null Spaces and Ranges

===================================================

linear map T: V->W 
nullT = {v : Tv = 0} is a subspace of V 

     id :   T(0) = 0       --- includes 0
closure : T(u+v) = Tu + Tv 
                 =  0 +  0 --- addition 
           T(au) =   a(Tu)
                 =   a( 0) --- scalar multiplication

===================================================

linear map T: V->W 
is injective iff (Tu = Tv then   u =  v) --- definition
             iff ( u != v then Tu != Tv)
             iff (null T = {0})

        (inj) null includes 0       --- T(0) = T(0) + T(0)
              ; v != 0 then Tv != 0 --- injectivity
              ; nullT = {0}

(nullT = {0}) suppose Tu = Tv 
              ; 0 = Tu - Tv = T(u-v)
              ; null = {0} includes u-v
              ; u = v

===================================================

linear map T:V->W 
rangeT = { Tv } is a subspace of W 

   T                T                 T
0 ---> 0; w1      <--- v1      ;  w <---  v
               w2 <---      v2 ; aw <--- av 
          w1 + w2 <--- v1 + v2 

id; closure

===================================================

linear map T:V->W 
is surjective iff (rangeT = W)

===================================================

Fundamental Theorem of Linear Maps 

dimV = dim nullT + dim rangeT 

basis of null T  : {u1 ... um} 
basis of      V  : {u1 ... um} union { v1 ...  vn}
                        ↓             ↓      ↓
basis of range T :     {0,}          {Tv1 ... Tvn}

===================================================

Claim : {Tv1 ... Tvn} is independent

                       suppose  c1Tv1  + ... + cnTvn = 0
                                  ↑             ↑
nullT = span{u1...um} includes c1(v1) + ... + cn(vn)                                

; c1v1 + ... cnvn = d1u1 + ... + dmum 
; c's = 0

since u1,..um,v1...vn is linearly independent

===================================================

  if dim V > dim W 
then linear map T : V->W is not injective (finite-dimensional)

                                    "null T"
basis of V : { u_1 ...  u_m} union { ... u_n} (cannot be {}) 
                ↓      ↓            ↓ 
basis of W : {Tu_1 ... Tu_m}         {0,}

===================================================

  if dim V < dim W 
then linear map T : V->W is not surjective (finite-dimensional)

basis of V : {  u_1 ...   u_m } 
                 ↓        ↓
basis of W : { Tu_1 .... Tu_m } union { ... v_n}
                  "range T"

===================================================

linear map T : V->V (finite-dimensional)

T injective iff       nullT = {0}
            iff dim range T = dim V
            iff     range T = V
            iff           T surjective 

===================================================

Systems of Linear equations

       fix A(j,k) ∈ F 
and define T : F^n -> F^m 

                T  
sum of x_k e_k ---> sum of x_k [ A(1, k) ] = [ sum of A(1,k) x_k ]
                               [   ...   ]   [        ...        ]
                               [ A(m, k) ]   [ sum of A(m,k) x_k ]
                        
           e_k ---> [ A(1, k) ]
                    [   ...   ]
                    [ A(m, k) ]    

  (i) {0} ⊆ null T 

 (ii) nonzero solution exists iff null T ⊋ {0}
                              iff T not injective 

(iii) system with 
      more variables then equations (n > m) 
      has nonzero solutions

      because T is not injective

 (iv) no solution            iff range T != F^m 
      for some choice of c   iff T not surjective 
                                       
      [ sum of A(1,k) x_k ]   [ c_1 ]  
      [        ...        ] = [ ... ] means Tx = (c1, ... cm)
      [ sum of A(m,k) x_k ]   [ c_m ] 

  (v) system with 
      more equations then variables (m > n)
      has no solution for some choice of the constatn terms 

      because T is not surjective.

3C. Matrices

Matrix of a linear map 

===================================================

m-by-n matrix A in F 


     [A(1,1) ... A(1,n)]
A =  [       ...       ]
     [A(m,1) ... A(m,n)]

A(j,k) = entry in row j, column k 

===================================================

linear map T : V->W 

basis of V = {v_1,...v_n}
basis of W = {w_1,...w_m}

M(T) is the m-by-n matrix defined by 

     T                  
v_k --->   [ A(1,k) ] w_1  ---> column k of M(T) 
         + [  ....  ]
         + [ A(m,k) ] w_m  

M(T) depends on bases as well as on T

===================================================

For matrices of the same size, entrywise: 

(A+C)(j,k) =  A(j,k) + C(j,k) --- addition 
( aA)(j,k) = aA(j,k)          --- scalar multiplication

===================================================

For linear maps S,T:V->W and k in F 

M(S+T) = M(S) +  M(T) --- addition  
M( kT) =        kM(T) --- scalar multiplication

===================================================

 let     F^(m,n) = {m-by-n matrices on F}
then dim F^(m,n) = mn 

===================================================

Rows, columns, and products

m-by-n matrix A

A(j,*) =    row j of A ; 1-by-n matrix
A(*,k) = column k of A ; m-by-1 matrix 

===================================================

Matrix multiplication

basis of U = {u_1 ... u_p}
basis of V = {v_1 ... v_n}
basis of W = {w_1 ... w_m}

              T      S 
linear map U ---> V ---> W  with M(S) = A , M(T) = B

u_k --->   [ B(1,k) ] v_1
             + [  ....  ]  
                 + [ B(n,k) ] v_n

                  S ↓                 
                                                                I
+ [ A(1,1) ]            w_1 + ... + [ A(1,n) ]            w_1  --->  [ (AB)(1,k) ] w_1 
+ [  ....  ]                +     + [  ....  ]                       [    ...    ]
+ [ A(j,1) ] [ B(1,k) ] w_j + ... + [ A(j,n) ] [ B(n,k) ] w_j  --->  [ (AB)(j,k) ] w_j 
+ [  ....  ]                +     + [  ....  ]                       [    ...    ]
+ [ A(m,1) ]            w_m +     + [ A(m,n) ]            w_m  --->  [ (AB)(m,k) ] w_m

===================================================

A m-by-n
B n-by-p 

then AB is the m-by-p matrix 

defined iff   (# columns of A)
            = (#    rows of B)

with

(AB)(j,k) = sum of A(j,r)B(r,k) ---    row j of A 
                                    column k of B

                 = A(j,*)B(*,k) --- row times column

===================================================

then M(ST) = M(S)M(T)

Matrix multiplication is not commutative (AB != BA)
               but it is distributive and associative.
