Invertible Linear Maps 

======================================

linear map T: V->W 
           is invertible 

iff exists linear map S: W->V (inverse of T)

with ST = I (on V)
     TS = I (on W)

======================================

inverse of linear map T: V->W 
                      is unique 

S1 = (    I) S1 
   = (S2  T) S1 
   =  S2 (T  S1)
   =  S2 (    I) = S2 

======================================

linear map T:V->W 

T is invertible iff   T is  injective 
                    & T is surjective 

with dim V = dim W (finite dimensional)

T is invertible iff T injective 
                iff T surjective 

(∵ Fundamental Theorem)

                  T

Change of basis

======================================

linear map T: V->V and one basis used twice 

M(T, (v1 ... vn)) := M(T, (v1 ... vn), (v1 ... vn))

======================================

(identity matrix)

identity matrix : I ∈ F^(n,n) 

                  with I(j,k) = 1 if (j = k) else 0 

for any square A 
        of the same size : AI = IA = A 

the symbol I denotes 
           both the identity operator and matrix

any single basis of V, M(I) = I 

======================================

(invertible matrix)

square A is invertible iff exists square B (same size)
                       with AB = BA = I 

such B is unique, written A^(-1)

======================================

 (i) (A^-1)^-1 = A
 
     since (A^-1)(A) = A(A^-1) = I 

(ii)   if A, C invertible of the same size 
     then (AC) is invertible with (AC)^(-1) = (C^-1)(A^-1)

     since (AC)(C^-1 A^-1) = A(C C^-1)A^-1
                           = A(     I)A^-1
                           = A        A^-1 = I 

     likewise (C^-1 A^-1)(AC) = I
