3A. Vector Space of Linear Maps

===================================================

Linear Transformation T : V -> W

       T
  au  --->   aT(u) 
+ bv  ---> + bT(v) 
     
===================================================

Linear Map Lemma 

v(1) ... v(n) : basis of V
w(1) ... w(n) : in W

then 
exists unique linear map T: V->W

      T
v(k) ---> w(k)

===================================================

( S +  T)v =   Sv +    Tv    --- addition
(aS     )v = a(Sv)           --- scalar multiplication
(aS + bT)v = a(Sv) + b(Tv)   --- operations on L(V,W) (pointwise)

∴ L(V,W) is a vector space  --- (id = 0 map)

===================================================

linear map  T : U -> V       T       S 
linear map  S : V -> W    u ---> Tu ---> S(Tu)

                                 ST 
linear map ST : U -> W    u -----------> S(Tu)

we need to prove that (ST) is linear

===================================================

 associativity (AB)C = A(BC)
      identity    TI = IT = T
distributivity (A+B)C  = AC + BC 
                A(B+C) = AB + AC 

ST = TS can fail (non-commutativity)

===================================================

  if T is Linear Map 
then T(0) = 0

3B. Null Spaces and Ranges

===================================================

linear map T: V->W 
nullT = {v : Tv = 0} is a subspace of V 

===================================================

linear map T: V->W 
is injective iff (Tu = Tv then   u =  v)
             iff ( u != v then Tu != Tv)
             iff (null T = {0})

===================================================

linear map T:V->W 
rangeT = { Tv } is a subspace of W 

===================================================

linear map T:V->W 
is surjective iff (rangeT = W)

===================================================

Fundamental Theorem of Linear Maps 

dimV = dim nullT + dim rangeT 

basis of null T  : {u1 ... um} 
basis of      V  : {u1 ... um} union { v1 ...  vn}
                        ↓             ↓      ↓
basis of range T :      {}           {Tv1 ... Tvn}

===================================================

  if dim V > dim W 
then linear map T: V->W is not injective (finite-dimensional)

                                    "null T"
basis of V : { u_1 ...  u_m} union { ... u_n} 
                ↓      ↓            ↓ 
basis of W : {Tu_1 ... Tu_m}          {}

===================================================

  if dim V < dim W 
then linear map T: V->W is not surjective (finite-dimensional)

basis of V : {  u_1 ...   u_m } 
                 ↓        ↓
basis of W : { Tu_1 .... Tu_m } union { w_m+1... w_n}
                  "range T"

===================================================

  if dim V = dim W (finite-dimensional)
then linear map T: V->W 

  is injective iff       nullT = {0}
               iff dim range T = dim V = dim W 
               iff     range T = W 
               iff           T surjective 

===================================================

Systems of Linear equations

       fix A(j,k) ∈ F 
and define T : F^n -> F^m 

                T  
sum of x_k e_k ---> sum of x_k [ A(1, k) ] = [ sum of A(1,k) x_k ]
                               [   ...   ]   [        ...        ]
                               [ A(m, k) ]   [ sum of A(m,k) x_k ]
                        
           e_k ---> [ A(1, k) ]
                    [   ...   ]
                    [ A(m, k) ]    

  (i) {0} ⊆ null T 

 (ii) nonzero solution exists iff T not injective 
                              iff {0} ⊊ null T  
      
(iii) no solution            iff T not surjective 
      for some choice of c   iff range T ⊊ F^m 
                              
 (iv) more variables then equations (n > m) ---> nonzero solution exists
      more equations then variables (m > n) ---> no solution
                                                 for some choice of c

3C. Matrices

Matrix of a linear map 

===================================================

m-by-n matrix A in F 


     [A(1,1) ... A(1,n)]
A =  [       ...       ]
     [A(m,1) ... A(m,n)]

A(j,k) = entry in row j, column k 

===================================================

linear map T : V->W 

basis of V = {v_1,...v_n}
basis of W = {w_1,...w_m}

M(T) is the m-by-n matrix defined by 

     T                  
v_k --->   [ A(1,k) ] w_1  ---> column k of M(T) 
         + [  ....  ]
         + [ A(m,k) ] w_m  

M(T) depends on bases as well as on T

===================================================

For matrices of the same size, entrywise: 

(A+C)(j,k) =  A(j,k) + C(j,k) --- addition 
( aA)(j,k) = aA(j,k)          --- scalar multiplication

===================================================

For linear maps S,T:V->W and k in F 

M(S+T) = M(S) +  M(T) --- addition  
M( kT) =        kM(T) --- scalar multiplication

===================================================

 let     F^(m,n) = {m-by-n matrices on F}
then dim F^(m,n) = mn 

===================================================

Rows, columns, and products

m-by-n matrix A

A(j,*) =    row j of A ; 1-by-n matrix
A(*,k) = column k of A ; m-by-1 matrix 

===================================================

basis of U = {u_1 ... u_p}
basis of V = {v_1 ... v_n}
basis of W = {w_1 ... w_m}

              T      S 
linear map U ---> V ---> W  with M(S) = A , M(T) = B

u_k --->   [ B(1,k) ] v_1
             + [  ....  ]  
                 + [ B(n,k) ] v_n

                  S ↓                 
                                                                I
+ [ A(1,1) ]            w_1 + ... + [ A(1,n) ]            w_1  --->    [ (AB)(1,k) ] w_1 
  [  ....  ]                        [  ....  ]                         [    ...    ]
+ [ A(j,1) ] [ B(1,k) ] w_j + ... + [ A(j,n) ] [ B(n,k) ] w_j  --->  + [ (AB)(j,k) ] w_j 
  [  ....  ]                        [  ....  ]                         [    ...    ]
+ [ A(m,1) ]            w_m +     + [ A(m,n) ]            w_m  --->  + [ (AB)(m,k) ] w_m

===================================================

Definition of Matrix multiplication

A m-by-n
B n-by-p 

then AB is the m-by-p matrix 

defined iff   (# columns of A)
            = (#    rows of B)

with
(AB)(j,k) = sum of A(j,r)B(r,k) ---    row j of A 
                                    column k of B

                 = A(j,*)B(*,k) --- row times column

∴ M(ST) = M(S)M(T)

===================================================

(AB)(*,k) = AB(*,k), (AB)(j,*) = A(j,*)B 

Ab = b_1 A(*,1) + ... + b_n A(*,n) --- linear combination of columns 
aB = a_1 B(1,*) + ... + a_n B(n,*) --- linear combination of rows 

===================================================

Matrix multiplication is not commutative (AB != BA)
               but it is distributive and associative. 

===================================================

Product as linear combinations of Columns or Rows

C m-by-c
R c-by-n

then (CR)(*,k) = CR(*,k) 
               = R(1,k)C(*,1) + ... + R(c,k)C(*,c) --- combination of columns 

     (CR)(j,*) = C(j,*)R 
               = C(j,1)R(1,*) + ... + C(j,c)R(c,*) --- combination of rows 

===================================================

Column-Row factorization and Rank 

 (i) column rank : dim span { A(*,1) ... A(*,n) } in F^(m,1) 
(ii)    row rank : dim span { A(1,*) ... A(m,*) } in F^(1,n)

column rank <= n (only n columns)
            <= m (subspace of F^(m,1))

===================================================

  A : m-by-n 
A^t : n-by-m (transpose) with (A^t)(k,j) = A(j,k)

  (i) (A+B)^t =      (A^t) + (B^t)
 (ii) ( kA)^t =     k(A^t)
(iii) ( AC)^t = (C^t)(A^t)

===================================================

suppose  (i)      m-by-n matrix A (in F) 
        (ii) c:= column rank of A >= 1

then exist m-by-c matrix C (in F)
           c-by-n matrix R (in F)

with A = CR 

each column of A = combination of the c columns of C
each    row of A = combination of the c    rows of R

===================================================

Step 1. Construct C

   reduce columns A(*,1) ... A(*,n) 
   into basis of its span 

   basis has length c --- column rank

Step 2. Construct R 

   A(*,k) = linear combination 
                   of columns of C

   A(*,k) = CR(*,k) --- coefficients of 
                        linear combination

===================================================

rank A := column rank of A 
        =    row rank of A

===================================================

Proof. 

consider A = CR (assume A != 0)

row rank A <= c = column rank A 

because every row in A is a 
        linear combination of the c rows of R 

take transpose to prove the rest.
